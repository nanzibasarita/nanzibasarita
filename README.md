## 💻 Projects

**[UIU BookHUB](https://github.com/nanzibasarita/UIU-BookHUB)** · *Team project*
A web platform where UIU students buy, sell, donate and discover academic books. Includes student and admin login, search and filters, wishlist, purchase requests, student-to-student chat, seller ratings and admin approval of listings. Built with PHP, MySQL, HTML, CSS and JavaScript.

**[Go-Green](https://github.com/Mahamudul496/Go-Green)** · *Team project*
A reward-based waste management system. Users submit recyclable waste with photos, schedule pickups and earn eco-points by waste type and weight. Points are redeemed for tree saplings, eco-friendly gifts and vouchers. Admins verify submissions and send notifications. Built with PHP, MySQL, HTML, CSS and JavaScript.

**[Road Ambulance](https://github.com/nanzibasarita/Road-Ambulance-Project)** · *Team project*
A desktop app for finding emergency ambulance and hospital support. Includes user registration and profiles, ambulance and hospital details, a map view, an SOS screen and a client-server chat. Built with Java, JavaFX and Maven.
